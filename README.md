INN Hotels Booking Cancellation Prediction

Project Overview

This project uses machine learning techniques to predict hotel booking cancellations based on historical booking data.

Objectives

* Identify key factors influencing hotel booking cancellations.
* Build predictive models using Logistic Regression and Decision Tree.
* Evaluate model performance using Recall and ROC-AUC.
* Reduce overfitting using pre-pruning and post-pruning techniques.

Methodology

1. Exploratory Data Analysis (EDA)
2. Feature Selection
3. Logistic Regression
4. Decision Tree Classification
5. Feature Importance Analysis
6. Pre-Pruning and Cost Complexity Post-Pruning
7. Model Evaluation and Comparison

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook
